# 周视图每日卡片禅道编号汇总设计

## 目标

在工作日志周视图的每日卡片中汇总当天日志包含的禅道编号，方便用户不打开日志详情即可确认当天关联的禅道事项。

## 范围

- 仅调整周视图每日卡片，不改变月视图、日志详情和现有周报项目汇总。
- 禅道编号展示在项目名称下方、工作内容摘要上方。
- 当天没有有效禅道编号时，不渲染禅道汇总行。

## 数据规则

`buildDateSummaryMap` 为每个日期生成 `zentaoNos`：

1. 读取当天所有日志的 `zentaoNo`。
2. 同时支持英文逗号和中文逗号分隔多个编号。
3. 去除编号首尾空白并忽略空值。
4. 按日志和编号首次出现顺序去重。
5. 不按项目再次分组；每日卡片展示的是当天汇总，现有周报仍按项目分别汇总。

## 界面设计

每日卡片存在有效编号时显示 `禅道：ZEN-101、ZEN-102`。该行使用次要文本样式，超长内容允许自然换行，避免挤压已有的人天、加班和工作内容信息。编号为空时整行隐藏，不显示“暂无”。

## 测试

- 工具函数测试覆盖中英文逗号拆分、去空、顺序去重和空值处理。
- 组件测试验证有编号时显示汇总，无编号时不显示禅道行。
- 运行相关工具函数测试、工作日志组件测试和前端构建。

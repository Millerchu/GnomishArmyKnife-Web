# 智订套餐额度实施计划

套餐使用页面提供比例、恢复时间和重置机会。用户从「套餐额度」为某个账号录入一次采集，查看最近快照与历史。额度与 API 用量、费用采用独立口径。

- 后端通过 `/ai-subscriptions/quota-snapshots` 保存及查询账号额度。复用应用授权与账号归属校验，按采集时间保存和读取，百分比限制为 0–100。
- 编辑器提供 ChatGPT、Grok 和 Muse 的初始窗口，允许补充或移除厂商没有展示的项目。Grok 明细分来源和 Bot，Muse 的剩余数量保持原单位，ChatGPT 手动重置逐条记录次数和到期。
- 快照保留厂商给出的百分比方向和重置提示。日期以 Asia/Shanghai 填写，厂商只显示倒计时或日期时保留原文。
- 前端检查切换账号、验证内容和历史展示，后端验证隔离、迁移和请求保存。
